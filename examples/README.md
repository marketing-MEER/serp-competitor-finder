# 📂 Sample data

`serp_export.csv` is a **made-up** SERP export: 12 CRM keywords × the top 10 results, in the same format as an
Ahrefs or Semrush SERP export (`Keyword`, `Volume`, `Position`, `URL`). The "you" site is `brightcrm.io`.
All brand sites in it are fictional; rankings for big platforms (YouTube, Reddit, G2…) are invented too.

```bash
serp-competitor-finder examples/serp_export.csv --domain brightcrm.io
```
